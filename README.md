# Admin Dashboard

This project is part of the Intermediate HTML and CSS curriculum from The Odin Project.

## Overview

Building this dashboard was a wonderful opportunity to practice and refine my front-end development skills. It focuses on creating structured, multi-section web layouts using modern CSS techniques.

## What I Learned

* **Advanced Layouts:** Gained a much deeper understanding of CSS Grid, specifically handling complex nested grids for sidebars, headers, and content areas.
* **Code Organization:** Practiced writing clean, semantic HTML to make styling and maintenance straightforward.
* **UI Refinement:** Improved my eye for spacing, alignment, and bringing a design concept to life from scratch.

## Built With

* HTML5
* CSS Grid and Flexbox
